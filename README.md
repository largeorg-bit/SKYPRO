# Проект "Банковское приложение"
## Описание:
Проект банковского приложения сделанный своими руками
## Проверить версию Python:
Убедитесь, что у вас стоит Python версией 3
## Установка Poerty:
Установить Poerty:
```
curl -sSL https://install.python-poetry.org | python3 -
```
## Установка:
1. Клонируйте репозиторий:
```
git clone git@github.com:largeorg-bit/SKYPRO.git
```
2. Перейдите в директорий проекта:
```
cd ваш-репозиторий
```
3. Установите необходимые зависимости:
```
poetry add --group lint flake8 black isort mypy
```
